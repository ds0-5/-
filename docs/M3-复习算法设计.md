## 一、现状：现在是怎么算的

文件：`app/services/quiz_service.py` 第 12~28 行（`sm2` 函数）

**中文版规则：**

```
【输入】
  上次的间隔天数
  难度因子（初始 2.5）
  连续答对次数
  这次答对没答对

【规则】
  如果答错了：
      连续答对次数归零
      下次间隔 = 1 天

  如果答对了：
      如果这是第 1 次答对  →  下次间隔 = 1 天
      如果这是第 2 次答对  →  下次间隔 = 6 天
      否则                →  下次间隔 = 上次间隔 × 难度因子
      连续答对次数 + 1

  难度因子微调（答得好涨、答得差降，最低 1.3）

【输出】
  下次间隔（几天后复习）
```

## 二、要解决的三个问题

**问题 1：所有题一视同仁**
「出栈序列」（高频考点）和「广义表深度」（边缘考点）用同一套间隔。

**问题 2：只有「对 / 错」两档**
学生「蒙对」和「真会」没有区别。

**问题 3：间隔涨得太快**
第 5 次答对就 93 天、第 6 次 232 天——一个学期才 120 天，等于后面就不复习了。

## 三、新规则（目标）

```
【输入】
  上次的间隔天数
  难度因子
  连续答对次数
  这次答对没答对
  考点权重          ← 新增
  知识类型          ← 新增

【规则】
  如果答错了：
      连续答对次数归零
      下次间隔 = 1 天

  如果答对了：
      如果这是第 1 次答对  →  下次间隔 = 1 天
      如果这是第 2 次答对  →  下次间隔 = 6 天
      否则                →  下次间隔 = 上次间隔 × 难度因子

      下次间隔 = 下次间隔 × 权重系数      ← 新增
      下次间隔 = 下次间隔 × 类型系数      ← 新增
      连续答对次数 + 1

  难度因子微调（和原来一样）

  下次间隔不能小于 1 天                 ← 新增
  下次间隔不能大于 60 天                ← 新增

【输出】
  下次间隔
```

**系数表（草案，可改）：**

| 考点权重 | 系数 | 效果 |
|---|---|---|
| 核心 | 0.7 | 间隔缩短 → 复习更勤 |
| 普通 | 1.0 | 不变 |
| 边缘 | 1.5 | 间隔拉长 → 复习更少 |

| 知识类型 | 系数 | 理由 |
|---|---|---|
| 记忆型 | 1.0 | 基准 |
| 概念型 | 1.0 | 基准 |
| 流程型 | 0.8 | 步骤容易忘，多练 |
| 设计型 | 1.2 | 综合题，练太勤收益低 |
