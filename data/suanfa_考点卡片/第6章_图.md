## 一、必背考点

### 考点1：图的基本概念
- **无向图**：边无方向。**有向图**：边有方向，称为**弧**。
- **入度** = 以该顶点为**终点（头）**的弧数；**出度** = 以该顶点为**起点（尾）**的弧数。
- 有向图顶点的**度 = 入度 + 出度**。
- **无向完全图**：任意两顶点间都有边，边数 = **n(n-1)/2**。
- **有向完全图**：任意两顶点间有两条方向相反的弧。
- 图可以没有边，但**不能没有顶点**。

### 考点2：度数与边数的关系（必考）
- 无向图：**所有顶点度数之和 = 边数 × 2**（一定是偶数）。
- 有向图：**所有顶点入度之和 = 出度之和 = 边数**。

### 考点3：图的存储
- **邻接矩阵**：n×n 方阵，A[i][j]=1 表示 i→j 有边。
  - 无向图的邻接矩阵**一定对称**；顶点度 = 该行（列）1 的个数。
  - 适合**稠密图**，稀疏图会浪费空间。
- **邻接表**：每个顶点一条链表，存**该顶点的所有邻接顶点**；适合**稀疏图**。

### 考点4：图的遍历
- **DFS 深度优先**：用**栈**或递归回溯，类似树的**先序遍历**。
- **BFS 广度优先**：用**队列**，类似树的**层次遍历**。

### 考点5：最小生成树（综合题高频）
- **Prim**：从某个顶点出发，每次选连接已选集合的最小边（按**顶点**扩展）。
- **Kruskal**：每次选**权值最小且不成环**的边（按**边**扩展），时间复杂度取决于**边数**。
- 最小生成树是极小连通子图；**连通图的生成树 = 该图的一个极小连通子图**。

### 考点6：最短路径
- **Dijkstra**：单源最短路径（非负权）。
- **Floyd**：多源最短路径。

### 考点7：拓扑排序与关键路径
- **拓扑排序**：AOV 网，结果**不唯一**，必须基于**有向无环图（DAG）**。
- **关键路径**：AOE 网，最长路径；⚠️「关键路径活动缩短，工程一定提前」——**错**（要看是否还是关键活动、是否唯一关键路径）。

## 二、核心公式速记

| 内容 | 公式/结论 |
|---|---|
| 无向完全图边数 | n(n-1)/2 |
| 无向图度数和 | 2 × 边数 |
| 有向图 | 入度和 = 出度和 = 边数 |
| 有向顶点度 | 入度 + 出度 |
| DFS 用 | 栈 / 递归 |
| BFS 用 | 队列 |

## 三、易错点清单
1. ❌「邻接矩阵适合稀疏图」——错，邻接矩阵适合**稠密图**，邻接表适合稀疏图。
2. ❌「BFS 用栈」——错，BFS 用**队列**；「DFS 用队列」——错，DFS 用**栈/递归**。
3. ❌「有向图度 = 边数×2」——错，那是无向图；有向图度 = 入度+出度。
4. ❌「拓扑排序结果唯一」——错，**不唯一**。
5. ❌「关键路径活动缩短，工期必提前」——错，不必然。
6. ❌ 无向图邻接矩阵不对称——无向图一定**对称**。
