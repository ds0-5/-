# 第4章 串、数组和广义表 · 考点卡片

> 权重：目标1 边缘｜常考题型：单选 / 填空 / 判断 / 应用｜拿分难度：★★☆☆☆（公式背熟即拿分）

---

## 一、必背考点

### 考点1：串的定义
- 串 = 零个或多个字符组成的有限序列。
- **串长** = 字符个数。`"algorithm"` 长度 = 9。
- **空串**：长度为 0，不含任何字符。
- **空格串**：长度不为 0，由空格字符组成。
- ⚠️ 空串与空格串**不是同一个串**（空串长 0，空格串长 ≥1）。

### 考点2：串的存储与匹配
- 存储：定长顺序 / 堆式顺序 / 链式（块链）。
- 模式匹配：找子串在主串中第一次出现的位置。
- **BF 算法**（朴素/穷举）：最坏时间复杂度 **O(n·m)**。
- **KMP 算法**：利用 next 数组避免主串指针回溯，时间 **O(n+m)**。

### 考点3：数组的地址计算（必考公式）
- 一维：`LOC(i) = a + i × L`
- 二维**行优先**（C/Pascal）：`LOC(i,j) = a + (i × n + j) × L`（n = 每行元素个数）
- 二维**列优先**（FORTRAN）：`LOC(i,j) = a + (j × m + i) × L`（m = 每列元素个数）
- 例：A[10][20]，每元素 2 字节，A[0][0]=100：
  - 行优先 A[6][6] = 100 + (6×20+6)×2 = 100 + 252 = **352**
  - 列优先 A[6][6] = 100 + (6×10+6)×2 = 100 + 132 = **232**

### 考点4：特殊矩阵的压缩存储（公式必背）
| 矩阵 | 存储空间 | k 的公式（1 起，下三角存 sa[k]） |
|---|---|---|
| 对称矩阵 | n(n+1)/2 | i≥j：`k=i(i-1)/2+j`；i<j：`k=j(j-1)/2+i` |
| 下三角 | n(n+1)/2+1 | i≥j：`k=i(i-1)/2+j`；i<j：`k=n(n+1)/2+1` |
| 上三角 | n(n+1)/2+1 | i≤j：`k=(i-1)(2n-i+2)/2+j-i+1` |
| 稀疏矩阵 | 三元组 / 十字链表 | 只存非零元素 (i,j,值) |

- 稀疏矩阵：非零元素很少（<5%），用**三元组表**（顺序）或**十字链表**（链式）存储。

### 考点5：广义表（必考，送分题）
- 定义：`LS = (a0, a1, ..., an-1)`，元素可以是**原子**也可以是**子表**。
- **长度** = 最外层元素的个数。
- **深度** = 括号的最大重数。
- **表头 GetHead(L)**：非空表的**第一个元素**（可能是原子，也可能是子表）。
- **表尾 GetTail(L)**：除表头外的其余元素组成的表（**一定是一个表**）。
- 例：`L=(a,(b,(c,d)),e)` → 长度 3，深度 3（(c,d) 是第 1 层，向外数到 (b,(c,d)) 是第 2 层，最外层是第 3 层）。
- `L=((a,b),c,d)` 的表头 = `(a,b)`（是子表，不是 a）。

## 二、核心公式速记

| 内容 | 公式 |
|---|---|
| 二维行优先 | `LOC(i,j)=a+(i×n+j)×L` |
| 二维列优先 | `LOC(i,j)=a+(j×m+i)×L` |
| 对称矩阵下三角 | `k=i(i-1)/2+j`（i≥j） |
| BF 最坏 | O(n·m) |
| KMP | O(n+m) |

## 三、易错点清单
1. ❌「空串和空格串一样」——错，空串长 0，空格串长 ≥1。
2. ❌「广义表的表头一定是原子」——错，可以是**子表**。
3. ❌「广义表的表尾可能是原子」——错，表尾**一定是表**。
4. ❌ 数组地址行优先/列优先公式记混——行优先乘**列数**，列优先乘**行数**。
5. ❌「对称矩阵存 n² 个元素」——错，只存 n(n+1)/2 个。
