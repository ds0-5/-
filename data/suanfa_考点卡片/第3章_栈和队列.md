# 第3章 栈和队列 · 考点卡片

> 权重：目标1 核心｜常考题型：单选 / 填空 / 判断 / 应用｜拿分难度：★★★☆☆

---

## 一、必背考点

### 考点1：栈（Stack）—— 后进先出 LIFO
- 插入叫**入栈（进栈）**，删除叫**出栈**，都只能在**栈顶**进行。
- ⚠️ 栈是**操作受限的线性表**，只能在一端（栈顶）操作。

### 考点2：出栈序列合法性（高频）
- 判断方法：**「后进先出」约束**——先入栈的元素，若它后面还有更早入栈的元素未出栈，就不能先出。
- 例：入栈 A、B、C、D、E，`C,E,D,A,B` 不可能——因为 E 出栈时，A、B 还在栈内且 A 在 B 下面，A 不可能先于 B 出栈。
- ⚠️ 记住：**「入栈过程中可以出栈」**，所以不是只有全入再全出一种。

### 考点3：队列（Queue）—— 先进先出 FIFO
- 插入在**队尾**，删除在**队头**。
- 最先进入的元素最先被删除。

### 考点4：循环队列（高频，必背公式）
- 用数组 `Q[0..m-1]` 存，牺牲一个单元来**区分队满和队空**：
  - 队空：`rear == front`
  - 队满：`(rear + 1) % m == front`
  - 元素个数：`(rear - front + m) % m`
- 例：m=10，front=3，rear=8，元素个数 = (8-3+10)%10 = 5。

### 考点5：栈/队列的经典应用
- 栈：表达式求值、括号匹配、递归（函数调用）、数制转换。
- 队列：层次遍历、缓冲区、广度优先遍历。
- ⚠️ 「检查圆括号配对」用**栈**；「图 BFS」用**队列**。

## 二、核心公式速记

| 内容 | 公式/结论 |
|---|---|
| 栈 | 后进先出 LIFO，栈顶操作 |
| 队列 | 先进先出 FIFO，队尾入、队头出 |
| 循环队列队空 | `rear == front` |
| 循环队列队满 | `(rear+1) % m == front` |
| 循环队列长度 | `(rear - front + m) % m` |

## 三、易错点清单
1. ❌「栈和队列都能在两端操作」——错，都只能在一端（栈顶/队头队尾分工）。
2. ❌「栈是先进先出」——错，栈是**后进先出**；「队列是后进先出」——错，队列是**先进先出**。
3. ❌ 循环队列队满队空条件记反——队空 `front==rear`，队满 `(rear+1)%m==front`。
4. ❌「栈、队列不是线性结构」——错，它们都是**线性结构**。
5. 出栈序列合法性：抓住「更早入栈且在栈底的元素，不能越过栈顶元素先出」。
