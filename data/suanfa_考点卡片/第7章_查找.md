# 第7章 查找 · 考点卡片

> 权重：目标3（25%）｜常考题型：单选 / 填空 / 判断 / 综合｜拿分难度：★★★★☆（ASL 计算是重点）

---

## 一、必背考点

### 考点1：查找的基本概念
- **平均查找长度 ASL** = Σ(第 i 个元素的查找概率 × 比较次数)。
- 等概率时，成功 ASL = (1/n)Σ 比较次数。

### 考点2：顺序查找
- 不要求有序，从头到尾逐个比较。
- ASL（成功）= **(n+1)/2**；时间复杂度 O(n)。

### 考点3：折半查找（必考，综合题固定题型）
- **前提**：必须**有序 + 顺序存储**（随机访问）。
- 过程：low、high 指向两端，mid=(low+high)/2；
  - 若 key < A[mid]，high = mid−1；
  - 若 key > A[mid]，low = mid+1；
  - 相等则成功。
- 时间复杂度 **O(log₂n)**。
- n 个元素最多比较 **⌈log₂(n+1)⌉** 次（31 个元素最多 5 次）。
- ⚠️ 查找失败时 low 与 high **交错**（low = high+1），这个位置就是 key 应插入的位置。

### 考点4：二叉排序树（BST）
- 左子树所有结点值 < 根 < 右子树所有结点值。
- **中序遍历**得到**递增有序**序列。
- 折半查找的判定树就是一棵二叉排序树。

### 考点5：平衡二叉树（AVL）
- 是特殊的二叉排序树；**平衡因子 = 左子树高度 − 右子树高度**，只能是 **−1、0、1**。

### 考点6：B 树 / B+ 树
- 多路平衡查找树，适合外存（文件系统、数据库索引）。本章考概念为主。

### 考点7：哈希表（Hash，综合题高频）
- **哈希函数**：常用**除留余数法** `H(key) = key % p`（p 取素数）。
- **哈希冲突**：两个不同关键字映射到**同一地址**，不可避免。
- **解决冲突**：
  - **线性探测再散列**：冲突后依次探测下一个单元（H+1, H+2, …），易产生**堆积（二次聚集）**。
  - 链地址法：同一地址的元素用链表串起来。
- **ASL**：等概率成功 ASL = 各元素查找次数之和 / 元素个数。

### 考点8：分块查找
- 块间有序、块内可无序；ASL 介于顺序查找和折半查找之间。

## 二、核心公式速记

| 内容 | 公式/结论 |
|---|---|
| 顺序查找 ASL | (n+1)/2 |
| 折半查找 | O(log₂n)，需有序+顺序存储 |
| 折半最多比较 | ⌈log₂(n+1)⌉ |
| 哈希函数 | H(key)=key%p（除留余数） |
| 线性探测缺点 | 堆积/二次聚集 |

## 三、易错点清单
1. ❌「折半查找适用链表」——错，必须**顺序存储**（随机访问）。
2. ❌「折半查找无需有序」——错，必须**有序**。
3. ❌「哈希冲突可以完全避免」——错，冲突**不可避免**。
4. ❌「线性探测不会产生聚集」——错，会产生**堆积**。
5. ❌「顺序查找要求有序」——错，顺序查找**不要求有序**。
6. 查找失败时 low/high 交错，别算错比较次数。
